# TABS 载具指令板

启用 TABS Order Tablet 和 TABS Vehicle Framework，重新进入单人地图，从工具第 6 组拿出 TABS Order Tablet。

1. 左键点击要指挥的 TABS 载具，默认进入路径模式。
2. 路径模式左键地面，追加一个移动点。按 Q 切换目标模式，左键目标追加一次开火。目标模式按 **Z 切换武器**、**X 切换弹种**，左键把当前组合写入这条射击指令。再次按 Q 切回路径模式。
3. 指令按点击顺序编号。移动点之间显示绿色路线，橙线表示从该路径点射击的目标。Backspace 撤销末条，R 清空计划并重新选车。
4. 手持工具按 F7 执行。F5 中止，计划保留。执行期间可以切换手持工具观察。再次按 F7 将从第一条重新运行。

例如，要编排“移动、射击、射击、移动、射击”，选车后点击地面 A，按 Q 点击目标甲和乙，按 Q 点击地面 B，再按 Q 点击目标丙，最后按 F7。

车辆逐点驾驶，路径请按可通行路段设置转弯点。每个射击指令使用编排该条指令时选定的武器和弹种，消耗实际弹药。静态目标保存地图坐标，动态目标跟随点击位置。炮口对准后开火，不保证弹着点。遇到车辆卡住、武器无法对准、弹药不足或目标被删除时，程序停止并显示原因。当前关卡保留一辆车的一套计划。

v3 在游戏的 tick 回调向原版车轮发送油门、转向和手刹。履带车通过左右驱动轮差速转弯，车辆加速、悬挂和碰撞由游戏物理计算。请在可行驶的地面设置路径点；卡住时指令板会停止。更新后重新加载地图，确认标题为 TABS ORDER TABLET v3。

## 安装

从项目根目录执行 `python tools/deploy_vehicle_recorder.py`。此版本沿用旧录制模组的本地目录和安装器，升级后在游戏内显示为 **TABS Order Tablet**。安装器会核对备份后更新独立工具及 TABS 主脚本中的桥接部分。卸载桥接可运行 `python tools/deploy_vehicle_recorder.py --uninstall`。
