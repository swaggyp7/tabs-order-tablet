# TABS Fusion 发布与安装说明

[English](../../tabs-vehicle-recorder/RELEASE.md) | **简体中文**

可编排原版车轮移动、停车射击和移动射击，支持各条指令独立选择武器和弹种、动态目标部位跟踪、多车计划、统一启动与 3/5/7/10 秒延迟。H 展开操作提示。

## 安装

需要单人游戏、TABS Vehicle Framework 及其必需项目。仅启用工具不会安装桥接。

从 [v0.6.3 Release](https://github.com/swaggyp7/tabs-order-tablet/releases/tag/v0.6.3) 选择下载：

- 普通版 TABS-Fusion-v0.6.3.zip：[安装教程](INSTALL.md)。
- 回放兼容版 TABS-Fusion-Hit-Replay-v0.6.3.zip：[兼容教程](HIT-REPLAY.md)。

退出游戏，备份自己的框架文件，核对适配哈希后按教程替换。工坊工具与本地副本只启用一个。启用模组并重载地图后从第 6 组拿出工具。兼容版须单独订阅 Hit Replay 界面，不要叠加独立替换包。

## 操作与限制

完整按键、队列和延迟行为见[操作指南](USAGE.md)。普通版全部执行为 F8；检测到回放桥接后改为 F6。原生弹药和装填照常消耗，车辆晃动及炮塔射界影响开火和命中。目标消失、车辆卡住、武器不可用或弹药不足会停止计划。卸载时恢复自己安装前的文件备份。
