## 选车与编辑

从工具第 6 组拿出 Fusion，左键选择 TABS 车辆。Q 依次切换路径、停车射击和移动射击目标模式。路径模式点击可通行地面添加终点；目标模式用 Z 选择武器、X 选择弹种，再用左键点击目标。

停车射击会追加一次停下后开火的指令。移动射击则先暂存目标，自动返回路径模式，直到点击路径终点才追加一条指令。单独选目标不占队列条目，G 可取消待设置终点的目标。完成后队列显示 MOVE+FIRE，橙线连接终点和射击目标。

例如：移动到 A → 射击甲 → 向 B 行驶并攻击乙 → 移动到 C。指令按顺序执行。Backspace 撤销末条；Delete 清空当前车指令，保留延迟。

## 移动射击

在指定路径段中持续跟踪目标，炮口对准且武器就绪时开火。到达终点立即结束该段射击，即使没能开出一炮也继续下一条。每一段需独立指定目标，普通移动不会继承攻击目标。动态目标跟随点击部位，静态目标保存世界坐标。

## 延迟与多车协同

T 为当前车循环选择 3、5、7、10 秒延迟，默认 3 秒。启动计划后先倒计时，再执行第一条指令。等待期间车辆制动，不瞄准或开火。执行中不能修改延迟；F5 也可以中止倒计时。

R 重新选车并保留已有计划。每辆车的指令、延迟和执行状态相互独立。F7 启动当前车；F8 启动所有有效且有指令的车辆。检测到 Hit Replay 桥接后，全部执行改用 F6。各车从同一次启动请求开始分别倒计时，正在运行或等待的计划不会重启。

进入正在执行的车辆会停止该车计划，进入其他车辆不会。所有计划只保留在当前关卡。

## 按键与界面

| 按键 | 操作 |
| --- | --- |
| 左键 | 选车 / 添加指令 |
| Q | 切换模式 |
| Z / X | 目标模式下选择武器 / 弹种 |
| F7 | 执行当前车 |
| F8，回放桥接下为 F6 | 全部执行 |
| F5 | 停止当前车 |
| T | 修改延迟 |
| R | 重新选车 |
| Backspace / Delete | 撤销末条 / 清空当前车队列 |
| G | 取消待设置终点的目标 |
| H | 展开 / 收起操作提示 |

左下角显示车辆、模式、延迟、当前附近的队列条目和状态；执行时显示倒计时或进度。H 展开帮助，面板按屏幕缩放，较长武器名会裁切。启用 Hit Replay 时，Backspace 也会关闭当前回放叠层。

## 使用限制

移动通过原版车轮和游戏物理实现，请选择可行驶地面并在转弯处加点。射击使用原生武器、弹药、装填和射速；车体晃动、炮塔射界与对准情况影响开火和命中，不做弹道提前量预测。路线卡住、目标消失、武器损坏或不可用、弹药不足时停止该车计划。每车最多 128 条指令。
